# Delhi Air Quality Data Analysis

## Project Overview
This project focuses on analysing air quality data of Delhi to understand pollution levels and identify trends in air pollution.

## Objectives
- Analyse air quality data of Delhi.
- Understand pollution trends.
- Identify variations in air quality.
- Create meaningful visualisations using Power BI.

## Tools & Technologies
- Python
- Microsoft Power BI
- GitHub
- Excel / CSV

## Project Files
This repository contains the datasets and project files related to Delhi Air Quality Data Analysis.

## Expected Outcomes
- Better understanding of Delhi's air quality.
- Identification of pollution patterns.
- Interactive dashboards and visual insights.
